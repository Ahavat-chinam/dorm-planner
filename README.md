# 🏠 שיבוץ חדרים לפנימייה

כלי ויזואלי לשיבוץ בחורים לחדרים בפנימייה — **קובץ HTML אחד, בלי התקנה, בלי אינטרנט**.
נבנה כדי לשבת עם החבר'ה, לגרור שמות בין חדרים, ולראות בזמן אמת מה נשבר.

**▶️ [פתיחת התוכנה](https://ahavat-chinam.github.io/dorm-planner/)** · או הורדת `index.html` והפעלה מקומית בלחיצה כפולה.

---

## מה זה עושה

**נפתח כמו תוכנה, לא כמו טופס** — במסך הראשון רואים את הפרויקט,
ומשם נכנסים פנימה: בניינים ← אגפים ← חדרים. בכל שלב רואים רק את מה שרלוונטי,
עם פירורי לחם למעלה כדי לחזור.

**האגף נראה כמו תוכנית קומה** — מסדרון באמצע, חדרים משני הצדדים,
ובמקומות הנכונים מקלחות, שירותים, כניסה, מדרגות ושטח מת.

**תבניות אגף** — רוב הפנימיות בנויות אותו דבר, אז בוחרים תבנית
(מסדרון קלאסי · שירותים באמצע · חדרים בצד אחד · אגף עם חדר מדריך · אגף מלא · ריק),
קובעים כמה חדרים וכמה מיטות, והכול נבנה בבת אחת. אפשר לגרור משבצות לסידור,
לשנות מה יש בכל אחת, ולשמור את התוצאה כתבנית משלכם לאגפים הבאים.

**הלוח** — לוחצים על בחור ונפתחת למטה מגירה עם **כל החדרים בכל האגפים**,
עם חיפוש וסימון מה מתאים ומה יפר כלל. לחיצה על חדר משבצת אותו — בלי לגלול ובלי לגרור.
מי שמעדיף גרירה — גם היא עובדת, כולל גלילה אוטומטית ומעבר בין אגפים תוך כדי.
לחיצה על 🔓 נועלת בחור במקומו כך שלא יזוז בטעות.

**כללים** — מגדירים תנאים ורואים מיד אם הם מתקיימים:

| סוג | דוגמה |
|---|---|
| 🚫 לא באותו חדר | פלוני ואלמוני — בשום אופן לא יחד |
| 🤝 ביחד באותו חדר | שלושה חברים שרוצים להיות ביחד |
| 📍 שיבוץ לחדר | פלוני חייב להיות ב-409 |
| 🚷 הרחקה מחדר | פלוני לא ב-405 |

לכל כלל שתי רמות: **בלתי מתפשר** (הפרה מפעילה אזעקה אדומה) או **עדיף**.
בכללי "באותו חדר" אפשר לסמן כמה בחורים שרוצים, לא רק שניים.

**הצעות תיקון** — כשיש הפרה התוכנה בודקת את כל ההעברות וההחלפות האפשריות
ומציעה מהלכים שמורידים הפרות, עם כפתור "בצע".

**שיבוץ אוטומטי** — ממלא את כל החדרים תוך כיבוד הכללים. אפשר לנעול חלק
מהבחורים ולתת לו להשלים רק את השאר.

**סימולציות** — שומרים גרסאות שיבוץ, רואים על כל אחת כמה הפרות יש בה,
ועוברים ביניהן בלחיצה כדי להשוות.

**יועץ AI** (רשות) — צ'אט שרואה את הלוח בזמן אמת, מייעץ, ויכול גם לבצע פעולות.
דורש מפתח Gemini חינמי. שלוש רמות הרשאה, מייעוץ בלבד ועד שליטה מלאה.

## איך מתחילים

אפשר בשתי דרכים:

**בלי קובץ** — במסך הפתיחה **🧱 בניית אגף מתבנית**, בוחרים פריסה,
קובעים כמה חדרים וכמה מיטות, ומוסיפים את השמות דרך ✏️ עריכה.

**מקובץ קיים:**

1. פותחים את `index.html`
2. במסך הפתיחה בוחרים **📥 ייבוא מקובץ**
3. מייבאים קובץ אקסל במבנה הזה:

| בחורים | חדר | מיטות | אגף |
|---|---|---|---|
| ישראל ישראלי | 405 | 4 | אגף 400 |
| משה כהן | 406 | 4 | אגף 400 |
| יעקב לוי | | | |

עמודת האגף אינה חובה. אפשר גם קובץ עם שמות בלבד, ולהוסיף חדרים ידנית.
**[`template.xlsx`](template.xlsx)** בריפו הוא תבנית מוכנה למילוי.

הייבוא קורא גם `.csv`, `.txt`, `.docx` ו-`.json`, ואפילו יודע לזהות
איזו עמודה מכילה שמות בטבלה עם כמה עמודות.

## פרטיות

כל הנתונים נשמרים **מקומית בדפדפן** על המחשב שלך. שום דבר לא נשלח לשום מקום.

היוצא היחיד מן הכלל הוא יועץ ה-AI, אם הפעלת אותו — ההודעות ותמונת מצב הלוח
נשלחות ל-Google Gemini. מפתח ה-API נשמר רק בדפדפן ואינו נכלל בקובצי הגיבוי.
בלי היועץ, התוכנה עובדת אופליין לחלוטין.
